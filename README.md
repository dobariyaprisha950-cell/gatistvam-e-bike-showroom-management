# Gatistvam E-Bike — E-Vehicle Showroom Management System

A real-world showroom management system designed for an E-vehicle business to manage day-to-day showroom operations efficiently.

## 🚀 Project Overview

Gatistvam E-Bike is a full-stack web application currently under development. The system is designed around real business workflows such as inventory management, sales, purchases, customer records, expenses and notifications.

## ✨ Key Features

- 🔐 User Login & Registration
- 📊 Business Dashboard
- 📦 Live Stock Management
- 🛒 Purchase Management
- 💰 Sales Management
- 👤 Customer Management & History
- 💸 Expense Management
- 🔔 Notifications & Alerts
- ⚙️ Settings & Business Configuration

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite3
- **Deployment:** Render (in progress)

## 📌 Current Status

The project is approximately **85% complete** and is currently under active development.

The remaining work includes connecting and completing parts of the sales, customer history and purchase history workflows.

## 🎯 Project Goal

The goal is to build a practical software solution that helps an E-vehicle showroom manage its business operations through a centralized system.
